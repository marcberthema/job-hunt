Keyword reliability this run

  • "DevOps Engineer" (N=22) and "DevSecOps Engineer" (N=25) both phrase-matched cleanly (91 and 19 results respectively) — the two usable keywords this run.
  • "Platform Engineer" reconfirmed as structurally unusable regardless of N — every N tried matches literal "engine" jobs (1,111 results dominated by mechanical/electrical/game-engine noise), consistent with the 2026-09-08 finding that this is inherent to Glassdoor's matching, not a URL-encoding bug.
  • "Site Reliability Engineer" reconfirmed the same inherent-noise problem — 266 results dominated by mechanical/electrical "reliability engineer" roles (rail, mining, hardware), not SRE. Neither keyword is worth retrying with different N values.
  • Did not run Cloud Engineer or Forward Deployed Engineer this pass — boundary for a follow-up run.
